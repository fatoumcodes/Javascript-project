# The Reading Room

The Reading Room is an interactive book discovery project built with JavaScript. Users can explore books, discover recommendations and interact with dynamic content.

The project was created as part of my web development journey, focusing on strengthening my JavaScript fundamentals and building interactive user experiences.

## Features

* Interactive book discovery
* Dynamic content and recommendations
* Mood-based book exploration
* Interactive artwork and UI elements
* Responsive design

## Built With

* HTML5
* CSS3
* JavaScript
* Tailwind CSS

## What I Practised

* JavaScript functions
* Arrays and objects
* DOM manipulation
* Event listeners
* Conditional logic
* Dynamic content
* User interactions
* Responsive web design

## Project Concept

The Reading Room was designed to make discovering books feel more personal and interactive, using mood and visual elements rather than a traditional book list.
